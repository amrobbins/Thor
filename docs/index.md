## Documentation principles

Thor documentation is organized around four complementary forms:

- **Tutorials** teach through complete, runnable workflows.
- **Guides** explain how to accomplish a specific task.
- **Concepts** explain the execution and training model behind the API.
- **API Reference** describes the exact supported Python interface.

The reference documentation will be generated from the same curated Python surface that ships in Thor releases, while narrative documentation and examples live in this repository.
