# Getting Started

This section will provide the shortest supported path from a clean Python environment to a working Thor model.

The completed getting-started flow will cover:

1. supported Python, NVIDIA driver, and CUDA runtime requirements;
2. installing the `thor-cuda` package;
3. verifying the installation and GPU runtime;
4. constructing a small network with the public Python API;
5. running the first training and inference workflow.

The examples added here will also run in documentation CI so that published setup instructions cannot silently drift from the released package.
