# Thor API stub snapshots

This directory is an input to the documentation build, not user-facing documentation.

Thor's native Python signatures are generated by nanobind during a normal Thor Python build. The documentation build must not regenerate them because doing so would require compiling and importing `_thor`. Instead, `tools/docs/sync_api_stubs.py` can copy an already-generated `thor` stub tree into a PEP 561-style `thor-stubs` package here.

Files under `thor-stubs/` are generated metadata. Do not hand-edit them. A later release/coverage check is responsible for verifying that the checked-in snapshot matches the stubs generated by the corresponding Thor build.
